# R5 事件段 Webb wild 与区组 RI（方法一页）

主回归是逐股票日的双向固定效应 OLS：含股票 FE、日历日期 FE、事件冻结 Hold 水平和 Closed×Hold；赛马加入指定控制水平与交互。主表的 SE 与 95% 区间来自股票、日期双向 CGM 聚类，交集是唯一股票×日期单元。有限样本修正为 (N−1)/(N−S−T−K+1)，股票肉矩阵乘 S/(S−1)、日期乘 T/(T−1)，减去单元肉矩阵乘 N/(N−1)；自由度 min(S,T)−1。协方差对角项为负时保留系数，SE/p/CI缺失并标状态。

对每个被检验交互 x_j，先精确吸收两组 FE，再用 FWL 对其他回归变量 Z 残差化：x*=M_Z x_j，y*=M_Z y。零假设为该项系数0，其他项允许非零，y*是限制模型残差。原始统计量为 β̂=(x*′y*)/(x*′x*)。

每条股票日按266去重映射归入唯一原始事件段；同段包括关闭日与分配给它的前后正常对照日。事件段得分 s_g=Σ_(it∈g)x*_(it)y*_(it)。一次重复给每段独立取 Webb 六点权重 {−√1.5, −1, −√0.5, √0.5, 1, √1.5}，等概率1/6，同段所有股票和日期共用该权重。β*_b=Σ_g w_bg s_g/(x*′x*)。这与固定设计下限制残差逐次重新吸收 FE、重新拟合全部 nuisance 后的该项系数完全相同；R5用得分聚合降低内存，不抽样股票、不把股票日当独立冲击。

全轮统一种子20261118、B=9999、46列原始事件权重，子样本使用原事件列，不因删样本而重新编号。同一次重复的事件权重在所有方程共享。双侧 p_wild=[1+Σ_b 1{|β*_b|≥|β̂|}]/(9999+1)。这是绝对系数检验，**并非每次重新估计标准误的 wild-t**；不把其称为studentized或对所有DGP精确的小样本检验。完整模型事件数与每个动态格的支持事件数分别报告。

区组 RI 直接调用266的 resampling_plan，只改种子与输出目录：为每个真实关闭段，在同年、同月、同起始星期、相同连续A交易日长度、全部为正常北向开放且落入原观测主窗日期的候选块中置换；同一次日历中各段不重叠。生成9999个可行日历，子样本取共同日历的日期投影，报告有效重复数。固定 FE 与 nuisance 后，通过稀疏股票×日期关联矩阵形成等价FWL二次型，逐次计算置换系数；实际关闭标签的二次型系数必须与OLS相差<1e−7。双侧RI p用同样加一公式。

赛马、多剂量、HKonly差异项的条件RI只重置被检验剂量的Closed交互，其余观测交互固定；它是条件日历诊断，不能解释为自然实验的无条件随机化p。原窗口有部分同年月星期候选限制，RI候选/独特日历数见randomization_support.csv和meta/resampling_status.json。多事件时间动态没有单一可重置Closed标签，因此报双向聚类与相同事件Webb，不伪造日历RI。扩展恢复+5动态也不借用原RI计划。

R5对266 FWL/CGM实现采用稀疏关联矩阵以满足4GB资源上限，数学公式及小样本修正不变；独立不平衡面板与原266函数逐系数/SE比对，并以重建后的IF/IH三种变换全样本基准对272最终表核对。数值证据见tables/numerical_adapter_vs_266_checks.csv及tables/R2_baseline_reproduction_checks.csv。

多重比较：每个规格×变换×被检验项的DelayIF/DelayIH二结果族同时给BH与Romano–Wolf stepdown。后者使用同一9999×46 Webb权重，将各方程限制bootstrap系数绝对值除该方程固定双向SE，依观测|t|从大到小对剩余最大统计量计算尾概率并作单调修正；不冒称逐次studentized。all_estimates.csv保留46个限制得分的JSON和FWL分母，可从种子独立复算。
